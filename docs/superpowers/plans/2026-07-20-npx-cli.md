# npx CLI Distribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npx skill-manage` 한 줄로 loopback Skill Atlas 서버를 실행하고 브라우저를 여는 공개 npm 패키지 `skill-manage@0.1.0`을 검증·게시한다.

**Architecture:** dependency-free ESM bin이 사용 가능한 loopback port를 고르고 packaged Astro standalone entry를 child process로 소유한다. npm tarball은 bin, production dist, README, MIT license만 직접 포함하며 runtime package dependencies를 정상 설치한다.

**Tech Stack:** Node.js >=22.12, npm 11, Astro 7 standalone Node adapter, Vitest 4, npm registry

## Global Constraints

- 기본 명령은 `npx skill-manage`다.
- 서버 host는 항상 `127.0.0.1`이며 public host option을 제공하지 않는다.
- 기본 port는 `4321..4420` 중 첫 available port다.
- explicit occupied/invalid port와 unknown args는 exit `2`다.
- browser open 실패는 non-fatal이고 URL은 항상 출력한다.
- CLI가 server lifecycle을 소유하고 SIGINT/SIGTERM을 전달한다.
- npm package는 public `skill-manage@0.1.0`, Node engine `>=22.12.0`, MIT다.
- tarball direct files는 `bin`, `dist`, `README.md`, `LICENSE`, package metadata로 제한한다.
- 기존 loopback Host/same-origin/content security와 scan behavior를 변경하지 않는다.
- publication 전에 exact tarball을 fresh npx process로 실행하고 root/API HTTP 200을 검증한다.

- [x] **Step 2: Implement the tarball smoke script**

`scripts/smoke-package.mjs` must:

1. run `npm pack --json` and parse the tarball filename/file list;
2. assert `package/bin/skill-manage.mjs`, `package/dist/server/entry.mjs`, client assets, README, LICENSE, package.json exist;
3. reject direct tarball entries under `package/src/`, `package/docs/`, `package/scripts/`, `.env`, and tests;
4. select a free loopback port;
5. spawn `npx --yes <absolute-tarball> --no-open --port <port>` in a fresh temporary cwd;
6. wait for the running URL, fetch `/` and `/api/inventory?mode=official`, assert HTTP 200 and `scanMode === "official"`;
7. signal the process group, require a clean exit, remove temp cwd and tarball in `finally`.

Use inherited npm cache but no repository cwd/module resolution in the temporary process.
