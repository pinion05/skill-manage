# Skill Manage PoC 설계

## 목표

macOS에 흩어진 코딩 에이전트의 `SKILL.md`와 skill 심볼릭 링크를 로컬 웹에서 빠르게 검색하고 탐색할 수 있는 읽기 전용 대시보드를 만든다. 사용자가 재검색 버튼을 누르면 현재 파일시스템을 다시 조사하며, 임시 TSV나 기존 보고서가 없어도 독립적으로 동작해야 한다.

## 범위

### 포함

- Astro SSR과 Solid.js 기반 로컬 웹 애플리케이션
- `/Users/pinion`, `/Applications`, `/Library`, `/usr/local`, `/opt/homebrew` 검색
- 정확한 `SKILL.md` 정의와 `skills.md` 일치 문서 구분
- skill 이름·설명·경로·설정 루트·파일 성격 수집
- skill 관련 심볼릭 링크의 정상·깨짐 상태 수집
- 이름·설명·절대경로 통합 검색
- 에이전트·파일 성격·링크 상태 필터와 정렬
- 페이지네이션
- `SKILL.md` Markdown 상세 보기
- 수동 재검색과 검색 시간·권한 오류 집계
- 모바일 대응 및 키보드 접근성

### 제외

- `SKILL.md` 수정·삭제·생성
- 심볼릭 링크 생성·복구·삭제
- 인터넷 공개 또는 원격 접속
- 파일 변경 자동 감시와 SSE
- 사용자 인증

## 아키텍처

Astro는 Node 어댑터의 standalone SSR 모드로 실행한다. 파일시스템 접근은 서버 전용 TypeScript 모듈에만 둔다. Solid.js island는 API에서 인벤토리를 받아 검색·필터·정렬·페이지네이션과 상세 패널 상태를 관리한다.

초기 화면은 `/api/inventory`의 메모리 캐시를 사용한다. 사용자가 재검색 버튼을 누르면 `POST /api/inventory/refresh`가 전체 검색을 새로 수행하고 캐시를 교체한다. 동시에 여러 재검색 요청이 오면 하나의 진행 중인 Promise를 공유한다.

상세 본문은 전체 인벤토리에 포함하지 않는다. `/api/skills/content?id=<stable-id>`가 현재 캐시에 등록된 경로만 허용하고 해당 파일의 내용을 읽는다. 이 검증으로 API가 임의 파일 읽기 기능이 되는 것을 막는다.

## 파일시스템 스캐너

### 검색 루트

- `$HOME`
- `/Applications`
- `/Library`
- `/usr/local`
- `/opt/homebrew`

존재하는 루트만 검색한다. `$HOME`은 `os.homedir()`로 계산하므로 사용자명이 바뀌어도 동작한다.

### 제외 디렉터리

- `.git`
- `Library/Caches`
- `.npm/_cacache`
- `.bun/install/cache`
- `.cache`
- `.Trash`

권한 거부와 사라진 파일은 전체 검색을 실패시키지 않고 오류 개수와 대표 경로로 기록한다. 디렉터리 순회는 제한된 동시성으로 수행해 파일 디스크립터 고갈을 방지한다.

### Skill 데이터

각 일치 파일에서 다음을 수집한다.

- 안정 ID: 정규화된 절대경로의 SHA-256 앞 16자리
- 파일명과 절대경로
- frontmatter의 `name`, `description`
- frontmatter가 없을 때 디렉터리 이름을 사용한 대체 이름
- 가장 가까운 `skills` 디렉터리
- 역추적한 에이전트 또는 설정 루트
- 파일 성격: user/global config, app bundle, app runtime, plugin/cache/vendor, installed package/source dependency, project/source local, backup/temp/fixture, other
- 수정 시각과 파일 크기

### 심볼릭 링크 데이터

경로에 `/skills/`가 있거나 이름이 `skills`인 심볼릭 링크를 조사한다.

- 링크 경로와 해석된 대상
- 정상 또는 깨짐 상태
- 대상 아래 실제 `SKILL.md` 존재 여부
- `/skills/` 앞부분에서 역추적한 설정 루트

심볼릭 링크 디렉터리는 일반 순회에서 따라가지 않아 순환과 중복 스캔을 방지한다.

## API

### `GET /api/inventory`

캐시가 없으면 한 번 검색하고 이후에는 현재 스냅샷을 반환한다.

응답에는 다음이 포함된다.

- 생성 시각과 검색 소요 시간
- 통계
- skill 목록
- 설정 루트별 집계
- 심볼릭 링크 목록
- 권한 오류 요약

### `POST /api/inventory/refresh`

새 검색을 수행하고 완성된 결과로 캐시를 원자적으로 교체한다. 실패하면 이전 캐시는 유지하고 오류 응답을 반환한다.

### `GET /api/skills/content?id=...`

현재 스냅샷의 ID와 일치하는 `SKILL.md`만 읽어 원문 Markdown을 반환한다. 최대 파일 크기는 1MiB로 제한한다.

## 화면 설계

### 상단

- 제품명 `Skill Atlas`
- 마지막 검색 시각과 소요 시간
- 재검색 버튼
- 전체 skill, 고유 이름, 설정 루트, 정상 링크, 깨진 링크 통계

### 탐색 영역

- 고정형 검색창
- 에이전트·파일 성격·링크 상태 필터
- 이름·수정일·경로 정렬
- 현재 결과 수와 필터 초기화

### 목록

데스크톱에서는 밀도 높은 표, 좁은 화면에서는 카드 목록을 사용한다. 각 항목은 이름, 한 줄 설명, 설정 루트, 성격 태그, 수정일과 경로를 표시한다. 50개 단위 페이지네이션으로 DOM 크기를 제한한다.

### 상세 패널

오른쪽 슬라이드 패널에서 다음을 제공한다.

- 이름과 설명
- 설정 루트·절대경로·파일 크기·수정 시각
- 같은 이름을 가진 다른 위치
- 안전하게 렌더링한 전체 Markdown 본문
- 경로 복사 버튼

읽기 전용 범위를 유지하기 위해 파일 열기, 수정, 삭제 버튼은 제공하지 않는다.

### 시각 방향

따뜻한 회백색 바탕, 잉크색 본문, 선명한 코발트 포인트를 사용한다. 과도한 카드 그리드를 피하고 인벤토리 도구다운 행 중심 구조를 채택한다. 경로는 고정폭 글꼴, 제목과 본문은 가독성 높은 산세리프를 사용한다. 장식보다 정보 계층과 상태 대비를 우선한다.

## 구현 아트 디렉션

- **Visual thesis:** 차가운 광물색 종이 위에 놓인 파일 캐비닛 색인표처럼 정밀하고 조용하며, 코발트 스캔 레일 하나가 현재성을 만든다.
- **Content plan:** 상단 명칭·재검색 상태 → 한 줄 통계 원장 → 검색·필터 작업대 → skill 목록 → 우측 상세 검사 패널 순서다.
- **Interaction thesis:** 최초 목록은 짧은 순차 등장, 재검색 중에는 스캔 레일이 이동, 행 선택 시 상세 패널이 빠르게 미끄러져 들어온다. reduced-motion에서는 모두 즉시 전환한다.
- **Palette:** mineral `#edf0f2`, porcelain `#f8fafb`, navy `#152239`, cobalt `#315acb`, signal red `#b83b4a`, healthy green `#16715c`.
- **Type:** 제목은 `Avenir Next Condensed`, 본문은 `Avenir Next`, 경로와 수치는 `SFMono-Regular`를 사용한다.
- **Signature:** 상단과 선택 행을 연결하는 얇은 코발트 스캔 레일을 한 곳에만 사용한다.

초기 방향의 따뜻한 회백색은 일반적인 AI 대시보드 인상과 겹칠 수 있어 더 차가운 mineral gray로 수정한다. 통계 카드 모자이크도 제거하고 숫자를 하나의 원장형 strip에 배치한다.

## 오류 및 빈 상태

- 검색 실패: 이전 데이터 유지와 비차단 오류 배너
- 권한 오류: 헤더 경고와 상세 목록
- 본문 파일 삭제: 상세 패널에서 재검색 안내
- 결과 없음: 현재 필터를 보여주고 필터 초기화 제공
- 초기 검색 중: 통계 스켈레톤과 진행 문구

## 보안

- 개발·미리보기 명령은 기본 localhost 바인딩을 유지한다.
- API는 쓰기 작업을 제공하지 않는다.
- 상세 파일 접근은 현재 인벤토리 ID allowlist로 제한한다.
- Markdown의 원시 HTML은 렌더링하지 않고 링크에는 안전한 속성을 적용한다.
- 스캔 오류에 파일 내용이나 시스템 비밀을 포함하지 않는다.

## 완료 조건

- `npm run dev`로 대시보드를 열 수 있다.
- 기존 `/tmp` 보고서 없이 현재 파일시스템을 검색한다.
- 2천 개 이상의 skill을 검색·필터·페이지 이동할 수 있다.
- 재검색 버튼으로 최신 스냅샷이 반영된다.
- 상세 패널에서 발견된 `SKILL.md` 본문을 읽을 수 있다.
- 정상·깨진 심볼릭 링크와 권한 오류가 구분된다.
- 어떤 API도 파일시스템을 변경하지 않는다.
- 테스트, 타입 검사, production build가 통과한다.
